# 🎓 Student ID Pro - Advanced Digital Identity System

A comprehensive, production-ready digital student ID system with advanced features, mobile apps, and free cloud deployment.

## 🚀 **Quick Start**

### **1. Clone & Setup**
```bash
git clone https://github.com/yourusername/student-id-pro
cd student-id-pro
```

### **2. Backend**
```bash
cd backend
npm install
npm run dev
```

### **3. Frontend**
```bash
cd frontend
npm install
npm run dev
```

### **4. Mobile App**
```bash
cd mobile-app
npm install
expo start
```

### **5. Deploy (Free)**
```bash
# Frontend to Vercel
vercel --prod

# Backend to Railway
railway deploy

# Mobile to Expo
expo publish
```
